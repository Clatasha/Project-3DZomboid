First public testing release of Project 3DZomboid.

## Download and run
Download **PZ-3D-Setup-v0.1.1.zip**, extract it, and run **Start-Setup.cmd**.

For **Windows and Project Zomboid Build 42.21**. Steam and standalone game folders are supported.

Includes Project Viewpoint, ZombieBuddy, and the temporary 42.21 compatibility JAR. Handles launcher configuration, file backups, and restoration. The game and optional 6244-model pack are not included.

On first launch, enable ZombieBuddy and Viewpoint, approve the Java mod, and start a new test save. Press **O** for 3D or **Shift+O** to switch first/third person.

If build detection is inconclusive, check your game menu and confirm Build 42.21 in the setup window. Launch Game starts the executable directly.

Initial gameplay testing passed on Windows. Please report issues with your Windows/game version and any error message.
